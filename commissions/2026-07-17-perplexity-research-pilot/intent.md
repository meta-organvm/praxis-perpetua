high-quality, citation-verifiable current-external evidence for four real SGO
commissions with no variable Perplexity spend and no unattended action.

## Prohibitions

- No API key creation, API credits, API calls, purchases, or automatic refill.
- No Computer, Scheduled Tasks, connectors, messages, publishing, or external
  writes.
- No fixed provider/model catalog and no model selection in Research mode.
- No client-private or essence-private provider transmission and no private
  connected sources.
- Every request declares P/O/C/E preservation separately from
  `public_only`, `sanitized_only`, or `forbidden` external transmission.
- No sensitive raw export in a tracked public path.
- No accepted packet with a broken citation or unsupported material claim.

it does not duplicate them.

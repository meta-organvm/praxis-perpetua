⏺ ★ Insight ─────────────────────────────────────
  importlib for hyphenated scripts: Python won't import extract-seeds as a
  module name (hyphens are invalid identifiers).
  importlib.util.spec_from_file_location lets us load any .py file by path and
  bind it to a clean module name. This is the canonical workaround for
  script-style files that weren't designed as importable packages.

  session-scoped fixtures: Parsing a 210KB markdown file on every test would be
  wasteful. scope="session" parses once, shares the result across all test
  functions in the entire pytest run.

  intentionally.

  unified source" hits consolidat, redundan, and unif (3 patterns), but the
  threshold is 1 — the test input needs to match the actual regex patterns more
